When an unlinked hardware device boots up, it initiates the pairing handshake by requesting a temporary, 6-character alphanumeric pairing code from the Ayphr Cloud.

---

## HTTP Request

```http
POST /api/devices/pair HTTP/1.1
Host: api.ayphr.com
Content-Type: application/json
```

### Authentication
**None**. This is a public hardware provisioning endpoint.

### Rate Limiting
- **20 requests per 15 minutes** per IP address.

---

## Request Body

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `serial` | `integer` | **Yes** | Unique hardware serial number (0 to 4,294,967,295, unsigned 32-bit integer). |
| `name` | `string` | No | Optional human-readable friendly name (maximum 64 characters). Defaults to `"Device <serial>"`. |

### JSON Body Example

```json
{
  "serial": 12345678,
  "name": "Living Room Monitor"
}
```

---

## Response

### `201 Created`
Returned when a pairing session is successfully initiated.

```json
{
  "code": "737ER4",
  "expiresAt": "2026-11-08T01:05:00.000Z"
}
```

#### Response Properties:
- `code` (`string`): A 6-character uppercase alphanumeric code using the unambiguous character set `ABCDEFGHJKLMNPQRSTUVWXYZ23456789` (excluding easily confused glyphs such as `0`, `O`, `1`, `I`).
- `expiresAt` (`string`): ISO-8601 timestamp after which the code expires (15 minutes from creation).

---

## Error Responses

| Status Code | Error Message | Description |
| :--- | :--- | :--- |
| `400 Bad Request` | `{"error": "invalid serial"}` | Missing serial or serial outside the valid 32-bit integer range. |
| `429 Too Many Requests` | `{"error": "Too Many Requests"}` | Exceeded rate limit of 20 requests per 15 minutes. Includes `Retry-After` header. |

  <TabItem label="Rust (reqwest)">
    ```rust
    use serde::{Deserialize, Serialize};

    #[derive(Serialize)]
    struct PairRequest<'a> {
        serial: u32,
        name: Option<&'a str>,
    }

    #[derive(Deserialize, Debug)]
    #[serde(rename_all = "camelCase")]
    struct PairSuccess {
        code: String,
        expires_at: String,
    }

    #[derive(Deserialize, Debug)]
    struct ApiError {
        error: String,
    }

    #[tokio::main]
    async fn main() -> Result<(), Box<dyn std::error::Error>> {
        let client = reqwest::Client::new();
        let payload = PairRequest {
            serial: 12345678,
            name: Some("Living Room Monitor"),
        };

        let response = client
            .post("https://api.ayphr.com/api/devices/pair")
            .header("Content-Type", "application/json")
            .header("Accept", "application/json")
            .json(&payload)
            .send()
            .await?;

        let status = response.status();
        if status == reqwest::StatusCode::CREATED {
            let pair_data = response.json::<PairSuccess>().await?;
            println!("Pairing Code: {}", pair_data.code);
            println!("Expires At:   {}", pair_data.expires_at);
            // Display pair_data.code on hardware LCD or terminal
        } else {
            let err = response.json::<ApiError>().await?;
            eprintln!("Pairing request failed (HTTP {}): {}", status, err.error);
        }

        Ok(())
    }
    ```

  <TabItem label="Rust (Embedded ESP32)">
    ```rust
    use esp_idf_svc::http::client::{Configuration as HttpConfig, EspHttpConnection};
    use esp_idf_svc::http::Method;
    use std::time::Duration;

    pub fn request_pairing_esp32(serial: u32, name: &str) -> Result<(String, String), String> {
        let config = HttpConfig {
            buffer_size: Some(4096),
            buffer_size_tx: Some(4096),
            timeout: Some(Duration::from_secs(15)),
            crt_bundle_attach: Some(esp_idf_svc::sys::esp_crt_bundle_attach),
            ..Default::default()
        };

        let mut connection = EspHttpConnection::new(&config)
            .map_err(|e| format!("HTTP init failed: {e}"))?;

        let body = format!(r#"{{"serial":{},"name":"{}"}}"#, serial, name);
        let content_len = body.len().to_string();

        let headers = [
            ("content-type", "application/json"),
            ("accept", "application/json"),
            ("content-length", content_len.as_str()),
        ];

        connection
            .initiate_request(Method::Post, "https://api.ayphr.com/api/devices/pair", &headers)
            .map_err(|e| format!("HTTP request initiation failed: {e}"))?;

        connection
            .write_all(body.as_bytes())
            .map_err(|e| format!("HTTP payload write failed: {e}"))?;

        connection
            .initiate_response()
            .map_err(|e| format!("HTTP response initiation failed: {e}"))?;

        let status = connection.status();
        let mut response_buf = Vec::new();
        let mut chunk = [0u8; 512];

        loop {
            match connection.read(&mut chunk) {
                Ok(0) => break,
                Ok(n) => response_buf.extend_from_slice(&chunk[..n]),
                Err(e) => return Err(format!("HTTP read error: {e}")),
            }
        }

        let response_str = String::from_utf8_lossy(&response_buf);

        if status == 201 {
            // Parse {"code":"737ER4","expiresAt":"..."}
            let parsed: serde_json::Value = serde_json::from_str(&response_str)
                .map_err(|e| format!("JSON parse error: {e}"))?;

            let code = parsed["code"].as_str().ok_or("Missing code in response")?.to_string();
            let expires_at = parsed["expiresAt"].as_str().unwrap_or("").to_string();

            Ok((code, expires_at))
        } else {
            Err(format!("Pairing failed with HTTP status {status}: {response_str}"))
        }
    }
    ```
