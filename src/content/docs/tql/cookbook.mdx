## 1. Environmental Monitoring

### Detect HVAC Overheating with Setpoint Deviation
Find any point where the ambient temperature exceeds the thermostat target setpoint by more than 1.5 °C while the compressor state is active:

```text
findAll( pt -> {pt.tempC > pt.targetTemp} & !{pt.tempC ~1.5~= pt.targetTemp} & {pt.compressor == "RUNNING"} )
  then sortDescending(tempC)
```

### Clean & Downsample Climate Readings for Dashboard Rendering
Clean noisy incoming station readings, fill null humidity measurements, clamp humidity to 0% - 100%, and resample into 15-minute averages:

```text
findAll( p -> {p.stationId == "LAB_EAST"} )
  then fill(humidity, 50.0)
  then clamp(humidity, 0, 100)
  then resample("15m", "avg", tempC)
```

## 2. Battery & Power Health

### Calculate Battery Depletion Velocity (Rate of Drain)
Compute the per-second drain rate on lithium-ion cells to detect sudden power leaks or short circuits:

```text
findAll( pt -> {pt.battery.voltage is not null} )
  then sortAscending()
  then rate(battery.voltage, voltDrainPerSec)
  then filter( pt -> {pt.voltDrainPerSec < -0.05} )
```

### Detect Low-Battery Threshold with Running Average Smoothing
Smooth high-frequency battery measurement fluctuations over a 10-point rolling window and trigger an alert if the smoothed level drops below 15%:

```text
findAll( p -> {p.device.serial in [1001, 1002, 1003]} )
  then movingAverage(battery.level, 10, batterySmoothed)
  then filter( p -> {p.batterySmoothed < 15.0} )
  then select(serial, batterySmoothed)
```

## 3. Industrial Predictive Maintenance

### Detecting Pressure Drops Across Valves
Monitor differential pressure across two transducers; flag points where differential drops below safety margins:

```text
findAll( p -> {p.pressureInlet - p.pressureOutlet < 5.0} & {p.valveState == "OPEN"} )
  then sortDescending(timestamp)
  then limit(20)
```

### Vibration Peak Anomaly Detection
Isolate high-frequency accelerometer spikes and compute statistical dispersion (standard deviation):

```text
findAll( pt -> {pt.accel.rms > 2.5} | {pt.status =~ "CRIT(ICAL)?"} )
  then summary(accel.rms, tempC)
```

## 4. Multi-Sensor Data Export

### Extract Clean CSV-Ready Fields
Omit internal debug registers, rename internal technical identifiers to friendly headers, and paginate the latest 100 records:

```text
findAll( p -> {p.status == "ACTIVE"} )
  then omit(rawAdc, debugFlags, sysTick)
  then rename(tempC, temperatureCelsius)
  then rename(airPressure, barometricHpa)
  then sortDescending()
  then limit(100)
```
