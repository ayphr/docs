This page provides an exhaustive quick-reference cheat sheet for all clauses, comparison operators, tolerance syntax, and pipeline operations in TelemetryQL.

---

## Grammar Overview

```text
<action>( <var> -> <expression> ) [ then <pipelineOp> ]*
```

---

## 1. Query Roots

| Root | Description | Return Shape |
| :--- | :--- | :--- |
| `findAll(p -> ...)` | Evaluates filter and returns all matching records | `T[]` |
| `select(p -> ...)` | Functional alias for `findAll` | `T[]` |
| `findFirst(p -> ...)` | Returns first matching record | `T \| null` |
| `findLast(p -> ...)` | Returns last matching record | `T \| null` |
| `count(p -> ...)` | Returns number of matching records | `number` |
| `exists(p -> ...)` | Checks if one or more records match | `boolean` |

---

## 2. Comparison Operators

All comparison conditions are placed within `{ ... }` braces:

| Operator | Meaning | Example |
| :--- | :--- | :--- |
| `<` | Less than | `{tempC < 25.0}` |
| `<=` | Less than or equal to | `{pressure <= 1013}` |
| `>` | Greater than | `{battery > 20}` |
| `>=` | Greater than or equal to | `{vibration >= 0.5}` |
| `==` / `=` | Equality | `{status == "ACTIVE"}` |
| `!=` | Inequality | `{status != "ERROR"}` |
| `field2` | Field-to-field comparison | `{tempActual > tempTarget}` |

---

## 3. Tolerance Operators

| Operator | Type | Example | Matching Range |
| :--- | :--- | :--- | :--- |
| `~<delta>~=` | Absolute | `{humidity ~0.5~= 52}` | `[51.5, 52.5]` |
| `~<delta>%~=` | Percentage | `{voltage ~5%~= 220}` | `[209.0, 231.0]` ($\pm 5\%$) |
| `~<delta>~= <field>` | Dynamic setpoint | `{tempC ~1~= targetTemp}` | `[targetTemp - 1, targetTemp + 1]` |

---

## 4. Advanced Condition Operators

| Operator | Category | Example |
| :--- | :--- | :--- |
| `in [...]` | Set membership | `{status in ["ONLINE", "STANDBY"]}` |
| `not in [...]` | Set exclusion | `{code not in [0, 200]}` |
| `between X and Y` | Numerical range | `{tempC between 18.0 and 24.0}` |
| `is null` / `is not null` | Null check | `{humidity is not null}` |
| `exists` / `missing` | Presence check | `{gps.latitude exists}` |
| `contains` | Substring match | `{message contains "fail"}` |
| `startsWith` | Prefix match | `{serial startsWith "AYP-"}` |
| `endsWith` | Suffix match | `{file endsWith ".csv"}` |
| `=~ "regex"` | Regex match | `{serial =~ "^[0-9]{8}$"}` |
| `!~ "regex"` | Regex non-match | `{log !~ "DEBUG"}` |

---

## 5. Logical Operators

| Operator | Meaning | Example |
| :--- | :--- | :--- |
| `&` | Logical AND | `{tempC > 20} & {humidity < 60}` |
| `\|` | Logical OR | `{status == "CRIT"} \| {tempC > 80}` |
| `!` / `not` | Logical NOT | `!{status == "FAULT"}` |
| `( ... )` | Precedence grouping | `( {a} \| {b} ) & {c}` |

---

## 6. Pipeline Operations (`then ...`)

### Sorting & Pagination
- `then sortAscending([field])`: Sort ascending (default: `timestamp`)
- `then sortDescending([field])`: Sort descending (default: `timestamp`)
- `then limit(count)`: Restrict maximum number of records
- `then offset(count)` / `skip(count)`: Skip first $N$ records
- `then slice(start, [end])`: Sub-array slice (0-based)
- `then head(count)`: Retrieve first $N$ records
- `then tail(count)`: Retrieve last $N$ records

### Projection & Manipulation
- `then select(f1, f2, ...)`: Keep only `timestamp` and specified fields
- `then omit(f1, f2, ...)`: Drop specified fields
- `then rename(from, to)`: Rename property from `from` to `to`
- `then compute(field, expr)`: Derive numeric field via arithmetic `(tempC * 1.8) + 32`

### Data Cleaning
- `then distinct([field])` / `dedup([field])`: Deduplicate points
- `then dropNulls(f1, f2, ...)`: Remove points with missing values
- `then fill(field, value)`: Fill nulls with fallback value
- `then fillPrevious(field)`: Forward-fill last observed value (LOCF)
- `then clamp(field, min, max)`: Bound values between `min` and `max`

### Time-Series Analytics & Reductions
- `then timeRange(start, end)`: Temporal bounding (Unix ms or ISO strings)
- `then resample(duration, aggFn, field)`: Downsample into temporal buckets (`"1m"`, `"5m"`, `"1h"`) using `avg`, `min`, `max`, `sum`, `count`, `first`, or `last`
- `then movingAverage(field, windowSize, [targetField])`: Smooth noise with rolling average
- `then diff(field, [targetField])`: Instantaneous delta (`v_t - v_{t-1}`)
- `then rate(field, [targetField])`: Rate of change per second (`delta_v / delta_t`)
- `then summary([f1, f2, ...])`: Statistical summary (count, min, max, avg, sum, stddev)
- `then avg(field)` / `min` / `max` / `sum` / `median` / `stddev` / `count()`: Direct scalar reduction
- `then groupBy(field)`: Group records by field value
- `then filter(p -> ...)`: Secondary pipeline filter
